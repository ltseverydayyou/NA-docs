Basic use

  1. Press the prefix key. Default is ;.
  2. Type a command like fly 3, noclip or view random.
  3. Use a backslash to run more than one command: fly 50\goto random\dex.
  4. Press TAB or tap a suggestion to complete a command.

How it works

Simple view of the main parts.

Core
  • Loader starts Nameless Admin and prepares shared state.
  • Commands handle aliases, arguments and command logic.
  • UI shows windows, settings, command search and tools.
  • Plugins load extra .na and .iy commands.

Command flow

  1. You type a command.
  2. Nameless Admin reads the command and arguments.
  3. Aliases and targets are resolved.
  4. The command runs and shows feedback.

Selecting players

Short names for picking targets.

Targets
  • all everyone
  • others everyone except you
  • me just you
  • random one random player
  • nearest closest player
  • farthest farthest player
  • alive alive players
  • dead dead players
  • friends Roblox friends
  • nonfriends not your friends
  • team your team
  • nonteam other teams
  • r15 R15 avatars
  • r6 R6 avatars
  • npc NPCs
  • cursor player under mouse
  • #<number> random amount
  • %<team> team name
  • age<days> account age
  • rad<studs> nearby players

Example: goto random teleports to a random player. view team watches your team.

Plugins

Basic .na examples.

API

One command

cmdPluginAdd = {
    Aliases = {"hello", "hi"},
    ArgsHint = "<name>",
    Info = "Say hi",
    Function = function(name)
        DoNotif("Hello "..tostring(name))
    end,
    RequiresArguments = true
}

Run another command

runCommand("fly 50")
runCommand("to", "random")
runCommand({"noclip"})

Put plugin files in the right folder, then reload the loader.
