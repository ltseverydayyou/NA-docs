Plugins

Current .na plugins use Plugin.new(...), not the old cmdPluginAdd style.

Luau
hello.na
local plugin = Plugin.new("Hello")

plugin:cmd("hello", "hi")
    :args("<name>")
    :info("Say hi")
    :requiresArgs()
    :run(function(ctx, name)
        ctx:notify("Hello " .. tostring(name), 3)
    end)

plugin:cmd("fastfly")
    :info("Starts fly at speed 50")
    :run(function(ctx)
        ctx:run("fly 50")
    end)

Plugin folders

Put files in the right place, reload, done.

Paths
  • Nameless-Admin/Plugins
    .na plugins
  • Nameless-Admin/PluginsIY
    .iy plugins
  • ctx:notify(text, time)
    send a Nameless Admin notification
  • ctx:run(command)
    run another Nameless Admin command
